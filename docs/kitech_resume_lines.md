## 불릿 초안 (한 줄씩 선택해서 쓸 것)

### EtherCAT / 통신 인프라
- Beckhoff EK1100 + EL3054 아날로그 입력 모듈로 레이저 변위 센서 4채널을 KRC4에 연결, KUKA WorkVisual에서 슬레이브 XML 등록 및 `$ANIN[]` 매핑까지 EtherCAT 네트워크 구성 전 과정 수행
- KUKA EthernetKRL로 KRC4 ↔ PC 간 TCP 통신 구성 — KRL 측 XML 설정 파일 작성, Python TCP 서버에서 관절각·토크 데이터를 실시간 수신·파싱해 가공 실험 중 데이터 로깅 파이프라인 구축

### 수직도 제어 (메인)
- 레이저 변위 센서 4개를 EtherCAT으로 KUKA KRC4에 연동, ATAN2 기반 법선 벡터 역산 알고리즘을 KRL로 구현해 곡면 소재 드릴링 수직도 오차 **0.098°** 달성
- KUKA RSI(Robot Sensor Interface) 실시간 보정 루프 적용, 정적 PTP 보정 대비 연속 수렴 가능한 폐루프 제어 구현
- 수직도 제어 알고리즘 연구 결과를 **KSPE 2023 추계학술대회** 포스터 논문으로 발표 (공동 저자, 초록 AS2023-0787)

### 강성 보완
- 35개 로봇 자세에서 F/T 센서·레이저 트래커 동시 계측으로 하중-변위 데이터 수집, MATLAB으로 전처리·시각화
- 마찰 소재 부착 전후 드릴홀 위치 오차 비교 실험으로 **56~147 μm** 오차 감소 확인

### 모듈 설계 / FEM
- Autodesk Inventor로 드릴링 모듈 3D 설계 및 FEM 정적 구조 해석 수행 (최대 Von Mises 24.24 MPa, 안전율 10.3×)
- 정밀 핀 정렬 지그 설계로 반복 탈부착 시 TCP 오프셋 편차 제거, 재캘리브레이션 없이 동일 정밀도 유지
